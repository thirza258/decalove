# Landing page artwork

`library-afternoon.jpg` is bundled with the frontend so the landing page does not
depend on the optional, generated game art under `public/images/`.

Created with the built-in image generation tool, then encoded as a JPEG at quality
85 for web delivery. The source image is 1536 × 1024.

Generation prompt:

> Use case: illustration-story. Asset type: a single landscape hero illustration for Decalove, a quiet Japanese high-school visual novel. Create a beautifully composed, hand-painted anime background of an empty school library in late afternoon. A wooden reading table in the foreground holds one closed blue notebook and a few blank cream postcards. Tall windows on the left look out onto soft green trees and distant school roofs; warm sunlight falls across the table and empty chairs. A modest bookshelf is on the right. Restrained, airy composition, subtle painterly paper texture, soft sage greens, warm cream, honey wood and dusty sky blue. A gentle sense of a story about to begin, calm and inviting, carefully drawn perspective. Landscape 3:2 framing, with the notebook and table visible in the central portion so the image also crops well to a square. No people, no lettering, no logos, no watermark, no added borders or UI, no glowing effects, no floating particles.
